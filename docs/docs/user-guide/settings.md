# Settings Guide

Configure Alpacabitollama preferences.

## Accessing Settings

- Menu: File > Preferences (Ctrl+,)
- Tray: Right-click > Settings

## General

- Theme (Light/Dark/System)
- Start on boot
- Minimize to tray
- Language

## Models

- Default model path
- GPU layer offload
- Default model selection

## API

- Server port
- CORS settings
- API key management
- Rate limiting

## Chat

- Temperature (0-2)
- Max tokens
- Stream responses
- Save history

## Appearance

- Font size
- Code theme
- Show timestamps
- Compact mode

## Reset

Reset to defaults via Help > Reset Settings.
